# Шаромир

Русскоязычная детская SPA-песочница с Countryballs. Парк открывается сразу на весь экран: ребёнок выбирает готового друга, место или мастерскую по крупным пиктограммам. Сервер, аккаунт и сетевые API не нужны.

[Открыть игру](https://bloadvenro.github.io/country-balls/)

На планшете Android откройте игру в Chrome и выберите установку приложения в меню ⋮. После первого полного открытия и подготовки офлайн-режима можно играть без сети.

## Запуск и проверка

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Проверка устанавливаемой офлайн-сборки:

```sh
npm run build
npm run preview
```

Откройте адрес из терминала. Для установки PWA нужен HTTPS (или `localhost`). После первого полного открытия приложение, шесть фонов, флаги, шрифты и локальные записи названий доступны без сети.

Браузерные проверки:

```sh
npm test
```

Playwright по умолчанию использует установленный Google Chrome. Для Chromium: `npx playwright install chromium`, затем `CHROME_CHANNEL=chromium npm test`.

Для GitHub Pages команда `npm run build:pages` готовит каталог `docs/`. Он публикуется вместе с исходниками.

## Как играть

1. На сцене уже ждут два готовых шарика. Кнопка **Друзья** открывает компактную ленту: одного готового шарика можно добавить несколько раз как независимых героев. **Место** показывает иллюстрированные карточки парка, площадки, праздника, космоса, подводного мира и ледяной бухты, **Мастерская** открывает редактор.
2. В мастерской сначала видны **Мои шарики**: существующего можно изменить, нового — создать. Ниже находятся 16 любимых флагов и единый прокручиваемый каталог **195 стран + Англия**. Одно нажатие выбирает флаг и один раз произносит название; кнопка динамика повторяет его.
3. Во вкладке «Мордочки» выберите глаза и рот по отдельности, затем добавьте наряды. Аксессуары можно добавлять повторно, двигать, поворачивать, увеличивать, снимать и отменять.
4. На сцене коснитесь героя или выберите его с клавиатуры, затем нажмите пиктограмму действия. Маленький значок одного человечка означает сольное действие, группы — действие с другом. Когда на сцене два героя, они начинают вместе сразу. Если героев больше, коснитесь подсвеченного партнёра. Рядом с поворотом шарика можно переключить направление лица. Мордочка в панели меняет настроение только у выбранного экземпляра до перезагрузки и не переписывает исходный шарик в коллекции.
5. В настройках отдельно переключаются голос, звуки действий и музыка. В каждом месте звучит своя инструментальная мелодия. При переходе в мастерскую музыка останавливается. Если браузер поддерживает нативный полноэкранный режим, там же появляется необязательная кнопка **На весь экран**. Игра никогда не включает его сама.
6. **Очистить сцену** убирает всех героев после подтверждения, но сохраняет фон, коллекцию и настройки. Пустая сцена сохраняется после перезагрузки.

Коллекция, сцена, фон и настройки хранятся в `localStorage` этого браузера и адреса. Формат и ключ сохранений v1 сохранены; к старым данным добавляется проверенный `backgroundId`. Незаконченный черновик мастерской не сохраняется.

## Ресурсы

В статической поставке находятся 196 SVG-флагов и 196 стабильных MP3, локально синтезированных Piper `ru_RU-denis-medium`. Фоны парка, площадки, праздника, космоса, подводного мира и ледяной бухты — оригинальные SVG-иллюстрации проекта.

Флаги используют `flag-icons` (MIT), шрифт Nunito — OFL; сведения о Piper и голосе Denis Medium и остальные тексты лицензий находятся в `public/licenses`.

[SPEC_AUDIT_RU.md](SPEC_AUDIT_RU.md) — исторический аудит исходных требований, а не отчёт о завершённом семейном тестировании. Локальные PWA-ресурсы проверяются отдельно.
